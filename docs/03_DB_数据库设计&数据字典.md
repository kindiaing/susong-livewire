## 2 数据库设计概述

- 数据库类型：MySQL 8.0
- 默认字符集：`utf8mb4`
- 默认排序规则：`utf8mb4_unicode_ci`
- 主键：统一使用 `bigint unsigned` 自增 ID，名称为 `id`
- 时间戳：统一使用 `created_at` / `updated_at`，删除标记使用 `deleted_at`（软删除）
- 金额字段：采用整数存储方案（cknow/laravel-money），数据库使用 `bigint` 存储最小货币单位，Model 层通过 Money Cast 自动转换：
  - 金额类（元→分）：`bigint`，存入时 ×100，如 `total_amount` 存 19990 表示 ¥199.90
  - 单价/成本类（元→厘）：`bigint`，存入时 ×10000，如 `price` 存 123450000 表示 ¥12,345.0000
  - 数量/重量类（→毫）：`bigint`，存入时 ×1000，如 `quantity` 存 5000 表示 5.000
  - 温度/折扣率（→百分之一）：`int`，存入时 ×100，如 `temperature` 存 185 表示 1.85°C
  - 坐标（→千万分之一）：`int`，存入时 ×10000000，如 `latitude` 存 23129347 表示 23.129347
- 状态字段：使用 `tinyint` 或 `varchar` 枚举，默认值为 0 或业务初始状态
- 多租户数据隔离：商家相关表含 `merchant_id` 字段；司机/拣货员相关表含 `user_id` 或 `driver_id` 字段

## 3 命名规范

| 项目 | 规范 |
| :--- | :--- |
| 表名 | 小写、复数、下划线分隔，如 `purchase_orders` |
| 字段名 | 小写、下划线分隔，如 `settlement_status` |
| 外键字段 | 关联表名单数 + `_id`，如 `merchant_id` |
| 索引 | 前缀 `idx_` + 字段名，如 `idx_merchant_id` |
| 唯一索引 | 前缀 `uk_` + 字段名，如 `uk_phone` |
| Migration | 时间戳 + 动作 + 表名，如 `2026_01_01_000001_create_users_table` |
| 中文目录 | 表头备注、字段注释、目录名使用中文 |

## 9 Seeder 体系设计

### 9.1 设计原则

| 原则 | 说明 |
| :--- | :--- |
| 核心/测试分离 | 核心数据（角色/权限/配置/审核节点）生产环境必需，测试数据仅开发/演示使用 |
| 总模块 + 分模块 | 总 Seeder 可一键导入全部，分模块 Seeder 可单独运行指定模块 |
| 双入口兼容 | 同时支持 `php artisan db:seed`（Laravel 原生）和 `php artisan admin:seed`（自定义命令） |
| 幂等安全 | 所有 Seeder 使用 `firstOrCreate` / `exists` 检查，重复运行不产生重复数据 |
| 默认管理员在 Migration | 管理员账号（seeding）在 users 表 Migration 中创建，不依赖 Seeder |

### 9.2 目录结构

### 9.5 双入口调用方式

#### 方式一：Laravel 原生 `db:seed`

```bash
# 导入全部（核心 + 测试）
php artisan db:seed

# 仅导入核心数据
php artisan db:seed --class=SystemDataSeeder

# 仅导入测试数据
php artisan db:seed --class=DemoDataSeeder

# 导入单个测试模块
php artisan db:seed --class=Database\\Seeders\\Demo\\OrganizationDemoSeeder
```

#### 方式二：自定义 `admin:seed`

```bash
# 导入全部（核心 + 测试）
php artisan admin:seed

# 仅导入核心数据
php artisan admin:seed --system

# 仅导入测试数据（全部模块）
php artisan admin:seed --demo

# 仅导入指定测试模块
php artisan admin:seed --demo=organization
php artisan admin:seed --demo=product
php artisan admin:seed --demo=finance

# 列出所有可用的 Seeder 模块
php artisan admin:seed --list

# 清空后重新导入
php artisan admin:seed --fresh

# 强制执行（跳过确认）
php artisan admin:seed --force
```
