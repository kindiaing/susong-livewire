# 测试清单索引

> 按功能/流程拆分的系统测试清单，每个文件对应一条可独立走通的业务链路。
> 测试过程中发现的 bug 统一记录到 `99-bug-tracker.md`。

## 使用约定

- **文件命名**：`编号-功能名.md`，编号两位数递增（01、02、03…）
- **清单结构**：每条流程给出「菜单入口 → 按钮名称 → 操作 → 预期结果」，按编号步骤执行
- **前置条件**：每个文件开头列出需要的账号、权限、基础数据
- **bug 记录**：测试中发现问题，记入 `99-bug-tracker.md`，格式：日期 / 流程文件编号 / 步骤 / 现象 / 严重程度 / 状态
- **状态标记**：每个步骤前用 `[ ]` 待测 / `[x]` 通过 / `[!]` 发现问题（详见 99-bug-tracker.md）
