
# 05 搜索选择与一键匹配测试清单

> 覆盖范围：供应商/商家下拉升级搜索选择（searchable-select 服务端搜索，面向生产环境 600-1000 家商家场景）、商家搜索支持英文逗号分隔多商家、退货单供应商展示优化、拣货任务一键匹配数量
>
> 关联提交：`ee662a5`（供应商侧）、`358b5d8`（商家侧）、`3e99437`（逗号分隔搜索）、`50a1c9b`（一键匹配）

## 前置条件

| 项目 | 要求 |
|---|---|
| 账号权限 | admin 超管 |
| 基础数据 | 供应商、商家若干（名称相近更佳，便于验证搜索）；一张「拣货中」拣货任务（含多 SKU、跨多订单明细）；「普通退货」与「关联退货」两种退货场景各一 |
| 交互约定 | 搜索选择组件：输入防抖 300ms 服务端搜索，最多返回 20 条，选中后按钮回显名称，可点 X 清空 |

- [ ] 3.1 关联退货模式：选择关联采购单后，供应商名称以只读文本展示（自动带出、不可改，不再是置灰下拉）

## 第四部分：商家搜索逗号分隔多商家（6 处）

> 规则：输入「A,B」同时按 A 和 B 搜索，命中任一关键词即显示；不含逗号时行为与原单关键词完全一致

- [ ] 4.1 商家管理列表：输入「商家A,商家B」结果同时包含两商家；输入单个名称与原行为一致（名称/联系人/电话任一命中）
- [ ] 4.2 客户账户列表：同上（按商家名称）
- [ ] 4.3 客户账户新建弹窗搜索：输入「A,B」候选同时出现两商家（前缀匹配）
- [ ] 4.4 应收汇总单弹窗商家搜索：输入「A,B」候选同时出现；多选标签、排除已选逻辑正常
- [ ] 4.5 配送线路详情「添加商家」弹窗：输入「A,B」候选同时出现（名称/手机号任一命中）
- [ ] 4.6 SKU 可见性商家搜索：输入「A,B」结果同时包含
- [ ] 4.7 边界：仅输入「,」不报错且不出全量；「A,,B」空关键词被忽略；关键词前后空格自动 trim；原有单关键词搜索结果不变

## 第五部分：拣货任务一键匹配数量

> 入口：库存 → 拣货任务 → 详情页右上角（仅拣货中状态显示）

- [ ] 5.1 按钮显隐：「一键匹配数量」仅拣货中状态显示；待分配/已完成不显示
- [ ] 5.2 点击后：全部待拣货明细实拣=应拣、状态变已拣货；SKU 汇总视图实拣列联动刷新
- [ ] 5.3 不覆盖：已录入实拣/差异的行数量与状态保持原样
- [ ] 5.4 不自动完成：匹配后任务保持「拣货中」，需拣货员核对后手动点「完成拣货」
- [ ] 5.5 差异联动：匹配后对缺货 SKU 录入实拣 < 应拣，正常生成差异单（原流程不受影响）
- [ ] 5.6 完成链路：全部明细处理完后点「完成拣货」，出库正常
- [ ] 5.7 空场景：无待拣货明细时点击，Toast 提示「没有待拣货明细，无需匹配」
- [ ] 5.8 防重：快速连点不重复处理（请求期间按钮禁用）
