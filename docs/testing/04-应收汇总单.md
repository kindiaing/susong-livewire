## 第一部分：新增应收大弹窗（核心流程）

> 页面入口：顶部导航「财务管理」→ 左侧子菜单「应收账款」（/receivables）→ 右上角「新增应收」按钮

- [ ] 1.1 点击「新增应收」打开大弹窗，标题为「新增应收（汇总单）」，默认显示所有商家的候选订单
- [ ] 1.2 候选订单范围正确：仅显示「已签收」且「未生成过应收单」的订单；已生成应收单的订单、未签收订单不出现在列表中
- [ ] 1.3 商家下拉筛选：选择某商家后，列表仅显示该商家候选订单
- [ ] 1.4 切换商家筛选时，之前勾选的订单自动清空（跨商家选择通过先选 A 商家勾选、再切 B 商家勾选实现）
- [ ] 1.5 勾选订单行高亮显示；表头复选框可全选当前筛选结果，再次点击取消全选
- [ ] 1.6 底部合计栏实时联动：已选 N 单、合计金额、将按商家生成 N 张汇总单；未勾选任何订单时「生成汇总单」按钮置灰不可点
- [ ] 1.7 合计金额正确：等于所选订单调整后金额（adjusted_amount，无则取 total_amount）之和，金额换算厘→元无误
- [ ] 1.8 「取消」关闭弹窗后重新打开，勾选状态与筛选已重置

## 第二部分：生成汇总单（核心流程）

- [ ] 2.1 仅勾选同一商家（如商家 A）的 2 单，点击「生成汇总单」：成功后弹窗关闭、Toast 提示、列表刷新
- [ ] 2.2 列表新增 1 张汇总单：新单号（RC 前缀）、关联订单列为空（不显示订单号）、金额 = 两订单金额之和、结算方式取首单、到期日 = 当天 + 商家账期（15 天）
- [ ] 2.3 点开该汇总单详情页：「订单」列显示「汇总单」文字（不显示链接、页面不报错）
- [ ] 2.4 查看汇总单备注：含每笔订单明细（如「单号 ¥金额 / ...」拼接）
- [ ] 2.5 生成后回到「新增应收」弹窗：刚才已生成汇总单的订单不再出现在候选列表（防重生效）
- [ ] 2.6 跨商家多选（勾选商家 A 和商家 B 各若干单）后生成：成功创建 2 张汇总单，各自金额、备注只含本商家订单，商家归属正确
- [ ] 2.7 生成后的汇总单在列表页走原有编辑小弹窗：仅可修改到期日和备注，保存成功 Toast + 列表刷新
- [ ] 2.8 收款确认/删除等原有行操作对汇总单同样可用（汇总单可正常收款核销）
