# 06 价格链路与促销明细测试清单

> 覆盖范围：成本价加权平均与订单财务快照、订单明细三价格展示与购物车自动取价、SKU 销售类价格一键填充、促销活动明细管理（八类 UI）、全局顶部加载进度条与 Toast 倒计时自动关闭
>
> 关联提交：`cabc847`（批次1 财务快照）、`51a7928`（批次2 三价格与自动取价）、`b5994d0`（批次3 一键填充）、`db0a823`（批次4 促销明细）、`5798886`（批次5 进度条与倒计时）

| 项目 | 要求 |
|---|---|
| 账号权限 | admin 超管（含 price.promotion.* 权限） |

## 第一部分：成本价加权平均与财务快照（批次1）

### 1A 采购入库加权平均成本

> 入口：采购管理 → 采购单 → 入库

- [ ] 1.1 零库存 SKU 首次入库：入库后 SKU 成本价 = 实际入库单价（直接取采购价，不套公式）
- [ ] 1.2 有库存 SKU 入库：入库后成本价 =（现库存 × 现成本 + 入库量 × 实际价）÷（现库存 + 入库量），手算核对
- [ ] 1.3 最近采购价：入库后 SKU 的 last_purchase_price 更新为本次实际入库单价
- [ ] 1.4 部分入库：只对实际入库量参与加权计算，未入库部分不影响

### 1B 拣货任务成本快照

- [ ] 1.5 生成拣货任务：任务明细带出成本价，有订单明细快照时取快照，无快照时取 SKU 当前成本
- [ ] 1.6 拣货完成不回写成本：拣货操作不改变 SKU 成本价

### 1C 订单明细财务快照

> 入口：订单详情 → 添加/编辑明细

- [ ] 1.7 新增明细：落库 original_price（原价）、discount_amount（优惠金额）、discount_type（优惠类型）、cost_price（成本快照）
- [ ] 1.8 编辑明细：快照字段按最新成交价重算更新
- [ ] 1.9 累加明细：快照正确（不串行、不覆盖其他明细）

## 第二部分：订单明细三价格展示与购物车自动取价（批次2）

### 2A 订单明细三价格预览

> 入口：订单详情 → 添加/编辑明细弹窗 → 选择 SKU

- [ ] 2.1 选择 SKU 后单价输入框下方展示三个价格：零售价（划线灰字）、成交价（加粗）、会员价（会员标签，仅会员价 < 成交价时显示）
- [ ] 2.2 命中促销活动时成交价旁显示「促销」红标签，成交价 = 促销价
- [ ] 2.3 无任何优惠时：成交价 = 零售价，无会员标签（会员价与成交价一致时不显示）
- [ ] 2.4 配置会员折扣活动后：会员价 < 成交价且显示会员标签
- [ ] 2.5 点「取价」按钮：单价填入成交价，同时带出快照（原价/优惠金额/优惠类型/成本）
- [ ] 2.6 手工改价后保存：优惠金额按新成交价重算，优惠类型记 manual

### 2B 购物车自动取价与订单快照

> 入口：购物车列表 → 添加购物车明细 / 生成订单

- [ ] 2.7 选择 SKU 自动取价：单价自动填入成交价（非会员口径），无需手填
- [ ] 2.8 切换商家自动重新取价：选了 SKU 后切换商家，单价刷新为新商家的门店差异化价
- [ ] 2.9 生成订单：订单明细快照完整（original_price/优惠金额×数量/discount_type/cost_price），金额与购物车一致
- [ ] 2.10 快照口径：购物车生成的明细优惠类型为 manual（购物车价与零售价不一致时）或 none（一致时）

## 第三部分：SKU 销售类价格一键填充（批次3）

> 入口：商品管理 → SKU 列表 → 新增/编辑弹窗 → 销售价格组

- [ ] 3.1 输入基准价后点「一键填充」：吊牌价、零售价、批发团购价、员工内部价、门店/小程序/配送三渠道基准价共 7 个字段同价填满
- [ ] 3.2 校验：基准价为空点击提示「请先填写基准价」；负数/非数字被拦截
- [ ] 3.3 不参与字段：成本价、采购价、最低/最高限价保持原值不被覆盖
- [ ] 3.4 编辑回显：打开编辑弹窗基准价自动回填当前零售价，可直接点填充
- [ ] 3.5 保存验证：填充后保存，列表与详情展示的价格与基准价一致

## 第四部分：促销活动明细管理（批次4）

### 4A 双入口与分组布局

> 入口1：财务对账 → 促销活动；入口2：财务对账 → 促销设置 → 活动明细分组

- [ ] 4.1 促销活动列表：活动名称为蓝色链接，点击跳转促销设置页并定位到该活动的明细分组
- [ ] 4.2 促销活动列表：操作列「明细」按钮同上跳转
- [ ] 4.3 促销设置页左侧导航含「活动明细」分组；顶部活动选择器切换活动
- [ ] 4.4 按活动类型显示对应明细表格（如满减活动只显示满减阶梯表，普通促销显示活动商品表），并提示可跳转会员折扣配置

### 4B 活动商品（普通促销）

- [ ] 4.5 新增：SKU 搜索选择（支持编码/商品名关键词），定价方式固定价/折扣率二选一，必填校验正确
- [ ] 4.6 同活动同 SKU 去重：重复添加提示错误
- [ ] 4.7 第二件定价：无/固定价/折扣率三选一，选固定价或折扣率时对应字段必填
- [ ] 4.8 编辑回显与保存、删除正常

### 4C 满减阶梯（满减活动）

- [ ] 4.9 新增：金额/件数门槛二选一，减免方式固定减/折扣/赠品三选一
- [ ] 4.10 赠品方式：赠品 SKU 搜索选择必填
- [ ] 4.11 启停开关：切换即生效（启用/禁用即保留/删除）

### 4D 优惠券（优惠券活动）

- [ ] 4.12 新增：满减/折扣/抵扣/运费券 4 类型分支校验（如满减需门槛+减免金额）
- [ ] 4.13 有效期：固定日期与领取后 N 天二选一
- [ ] 4.14 编辑、删除、启停正常

### 4E 组合套餐（套餐活动）

- [ ] 4.15 新增：套餐明细行可动态加行/删行（≥1 行），每行 SKU 搜索 + 数量
- [ ] 4.16 原价合计自动计算：按明细行零售价 × 数量求和，展示正确
- [ ] 4.17 编辑回显：明细行按 sort 排序回显，更新后旧明细删除重建无残留

### 4F 秒杀 / 拼团 / 清仓临期

- [ ] 4.18 秒杀：秒杀价、总库存、每人限购、起止时间必填校验；编辑回显时间格式正确
- [ ] 4.19 拼团：成团人数上限必须大于下限（违反提示错误）；团价、时限必填
- [ ] 4.20 清仓临期：临期类型必填临期截止日期；固定价与折扣率至少填一项

### 4G 会员折扣关联活动

- [ ] 4.21 会员折扣弹窗可关联促销活动（选择器含全部活动）；不关联则为全局常驻规则
- [ ] 4.22 关联后列表可按活动维度查看，编辑回显正确

### 4H SKU 搜索组件

- [ ] 4.23 空关键词打开显示默认 20 条（按编码排序），label 格式「编码 - 商品名」
- [ ] 4.24 关键词命中编码或商品名均显示；底部「加载更多」翻页追加不重复；X 清空恢复默认列表

## 第五部分：全局加载进度条与 Toast 倒计时（批次5）

### 5A 顶部加载进度条

- [ ] 5.1 任意 Livewire 交互（搜索、翻页、保存）触发时页面顶部出现蓝色渐变进度条
- [ ] 5.2 请求进行中进度条推进至约 80% 并停住；完成后快速到 100% 淡出消失
- [ ] 5.3 请求失败进度条同样收尾退出（不卡住）
- [ ] 5.4 空闲时进度条不可见、不遮挡导航栏交互

### 5B Toast 倒计时与自动关闭

- [ ] 5.5 成功类 Toast（如保存成功）：底部出现细倒计时条从满宽线性缩减，约 3 秒后自动关闭
- [ ] 5.6 错误/警告类 Toast：约 5 秒自动关闭，倒计时条颜色与类型色一致（红/黄）
- [ ] 5.7 点击 Toast 主体或 X 按钮：立即关闭
- [ ] 5.8 多条 Toast 并存：各自独立倒计时互不影响
- [ ] 5.9 深色模式下倒计时条与配色正常显示
