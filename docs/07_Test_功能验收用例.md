
# 功能验收用例

对应 PRD 版本：V1.2
对应 FSD 版本：V1.2
技术栈：Laravel 13 + Livewire 4.x + Tailwind CSS 4.2+ + Alpine.js + PHP 8.3+ + MySQL 8.0 + Redis 7.x

---

## 1 文档说明

### 1.1 用例编写规范

- 每个功能模块一个章节，包含多个测试用例
- 用例格式：用例编号、用例名称、前置条件、操作步骤、预期结果、优先级
- 优先级：P0（阻塞级）、P1（关键路径）、P2（正常功能）、P3（边界/异常）

### 1.2 用例编号规则

`TC-{模块缩写}-{序号}`，如 `TC-USER-001`

| 模块缩写 | 对应模块 |
| :--- | :--- |
| USER | 用户与权限管理 |
| ORG | 组织主体管理 |
| PROD | 商品管理 |
| PUR | 平台统采 |
| ORDER | 客户直采 |
| INV | 库存管理 |
| LOSS | 损耗管理 |
| PICK | 拣货管理 |
| DELI | 物流配送 |
| DISC | 差异处理 |
| FIN | 财务对账 |
| PRICE | 价格策略 |
| APPR | 审核管理 |
| SYS | 系统支撑 |
| WX_M | 微信小程序商家端 |
| WX_D | 微信小程序司机端 |
